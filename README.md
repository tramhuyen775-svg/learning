# Chinese Study · HSK 3.0 (cấp 1–3)

Bản cập nhật cho repository GitHub Pages hiện tại.

## Thay thế ứng dụng cũ
1. Mở repository `hsk-chinese-study`.
2. Mở lần lượt `index.html`, `sw.js`, `manifest.json`, `icon.svg`.
3. Với mỗi tệp: bấm biểu tượng bút chì (Edit), thay toàn bộ nội dung bằng tệp cùng tên trong gói này, rồi **Commit changes**.
   - Cách dễ hơn: Add file → Upload files, kéo 4 tệp mới vào; xác nhận **Replace** nếu GitHub hỏi.
4. Chờ GitHub Pages cập nhật. Mở lại website bằng Ctrl+F5.

## Dữ liệu
- Tải 300 từ HSK 1, 200 từ HSK 2 và 500 từ HSK 3 từ bộ dữ liệu công khai được chép từ đề cương HSK 考试大纲 tháng 11/2025.
- Các trường chữ Hán, pinyin, từ loại, mã mục và trang nguồn là dữ liệu đối chiếu; nghĩa tiếng Việt/ ví dụ không có sẵn trong dữ liệu gốc. Bản này có một số nghĩa Việt phổ biến được biên soạn bổ sung; người học có thể tự nhập và lưu nghĩa/ví dụ còn thiếu.
- Dữ liệu từ vựng được tải lần đầu cần Internet; sau đó bản sao JSON được lưu trong trình duyệt. Ghi chú và tiến độ lưu cục bộ trên trình duyệt/thiết bị.
- Phần ngữ pháp là ghi chú học tập biên soạn thêm, không phải bản dịch chính thức của đề cương.
- Nguồn: https://github.com/uranbekanarbaev/hsk-3.0-vocabulary-dataset
- Bản quyền và phạm vi sử dụng dữ liệu nguồn: xem LICENSE.md trong repository nguồn. Ứng dụng không liên kết hoặc được bảo trợ bởi đơn vị tổ chức kỳ thi.
